# Dataset Setup

## Dataset

This project uses the Kaggle **Give Me Some Credit** dataset. Raw dataset files are intentionally excluded from the repository and must be downloaded separately by each contributor.

Do not automatically download or redistribute the dataset through project code.

## Local Directory Layout

Place the downloaded files in the following repository-relative structure:

```text
data/
├── raw/
│   ├── cs-training.csv
│   ├── cs-test.csv
│   ├── sampleEntry.csv
│   └── Data Dictionary.xls
├── interim/
└── processed/
```

The verified SHA-256 for `cs-training.csv` is:

```text
1bd46da486a5708c58c7b01a034fae2a13b327f6f7b62ea7ba4fe3b5824b24ac
```

## Data Handling Rules

- Dataset files must not be committed as part of model code.
- Raw data is read-only.
- Interim and processed data must be generated by code.
- `data/processed/split_manifest.csv` will be generated during Stage 2 and must not be committed.
- The Kaggle official test set has no labels and must not be used for local supervised evaluation.
